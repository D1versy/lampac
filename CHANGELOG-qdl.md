# Changelog форка (qdl_fork_version)

Маркер версии живёт в `Modules/LampaWeb/plugins/lampainit-invc.js` (`window.qdl_fork_version`,
виден в консоли клиента). ⚠️ Правило владельца: при КАЖДОМ фиксе клиентских плагинов
(`qdl.js`/`lampainit-invc.js`) бампать минор. До 2.16 полный changelog жил комментарием прямо в
invc и отдавался каждому клиенту (~6.5 КБ на каждый старт) — теперь здесь.

- **2.0** — умная выдача раздач (⭐ скоринг, серии/дата/🔔) + охота за сериями по всем раздачам (`/qdl/episodes`, серии-доноры «врем.», tl-таймлайн) + SWITCH-переключение.
- **2.1** — фиксы ревью: аудио доноров по своему hash, SWITCH-тост без «скачана».
- **2.2** — пункт меню «D1VERSY LIVE»: записи видеорегистратора (день → камеры с записями → плеер, прокси `/qdl/live/*`).
- **2.3** — весь день ОДНОЙ записью с одним таймлайном (склеенный HLS `/qdl/live/day`), фрагменты — запасной путь.
- **2.4** — раздел «D1versy Live» — эфир (живая сетка камер, rolling-HLS `/qdl/live/watch/*`); прежний раздел записей переименован в «D1versy Records».
- **2.5** — «D1versy Records» → «D1versy Rec».
- **2.6** — iPhone: эфир в НАТИВНОМ плеере iOS (прямой click-жест, `<video>` без playsinline, фолбек в VLC, `qdl_ios_live` auto/off); сетка эфира по центру и во всю ширину; видимый фокус пульта в Rec/камере/Уведомлениях.
- **2.7** — фикс iOS-эфира: видимый оверлей вместо скрытого `<video>` (авто-фуллскрин WebKit флакал со второго раза), явный webkitEnterFullscreen, попытки чистят только свой элемент (двойной тап больше не роняет в VLC).
- **2.8** — Rec на пустом «сегодня» сам прыгает на последний день с записями (пустой день на ТВ выглядел как «нет навигации»).
- **2.9** — зеркало прогресса устройства (file_view ↔ нативное KV AndroidJS, ключ `qdl_file_view`) — resume переживает смену хоста LAN↔внешний на iPhone/Mac/Android, браузер не затронут; выкл: `qdl_tl_mirror='off'`, фолбэк «всегда с начала» — `player_timecode='again'`; rawPlay унифицирован на pickTimeline; инварианты слияния: сид-метка t=1, кламп меток из будущего, уважение очистки истории, бюджет посева=кап.
- **2.10** — скорость: прогрев кеша сервера при открытии карточки скачанного (`/qdl/warmup`: голова+хвост файла в page cache + ffprobe-кеш) и прогрев следующей серии при старте плейбека; мемоизация fetchEpisodes (TTL 45 с); сервер: кеш резолва hash+index→путь, кеш ffprobe-дорожек, переиспользование SID-сессии qBittorrent, immutable-кэширование app.min.js/qdl.js/постеров.
- **2.11** — свой ЭКРАН СЕРИЙ (`qdl_episodes`) вместо селектбокса: длинные списки скроллятся на ТВ, «назад» из плеера возвращает в список серий, озвучка помнится и меняется кнопкой; отметки ✓/►N%; общий фикс селектбоксов (upstream-баг mheight — `fixSelectHeight`).
- **2.12** — номер серии бейджем в начале строки экрана серий (`epNumber`) — на iPhone длинные имена обрезались.
- **2.13** — синк с upstream 1.45 + включён модуль Music (флип manifest `enable:true`, клиентам `/music.js`) + свежие yaml-источники NextHUB.
- **2.14** — только НАШИ уведомления: AppPatch режет upstream-колокольчик (иконка Notice + NoticeCub), пункты меню Релизы/Расписание/Подписки, фоновый TimeTable-парсер (TMDB каждые 30 сек) и ряды «Скоро выйдут»/«Недавно вышли»; фиксы дублей qdl-колокольчика/бейджа (dedupe+first, in-flight poll, синглтон `qdl_plugin_loaded`, агрегация тостов); CSS-фолбэк на случай смены tree; `disable_features.subscribe=true`.
- **2.15** — локализация внешних источников (карта — Media-server `claude/11`): клиент ходит ТОЛЬКО на наш сервер (исключения: YouTube-трейлеры, стрим балансеров) — форс `proxy_tmdb=true` каждую загрузку (LAN-клиенты по GeoIP получали false и ходили на TMDB напрямую), `lampa_settings.mirrors=false` (проба зеркал CUB), `lampa_settings.geo=false`, watch-пинг `$.get('tmdb.<cub>/watch?id=')` → локальная заглушка `/cub/api/checker` (XHR-патч); сервер: MyLocalIp-хук вместо api.ipify.org, прогрев каталога CatalogWarmup, вендор плагинов магазина расширений (`/ext/*`).
- **2.16** — скорость (боевой лог — Media-server `claude/06` §AS): precompressed brotli-q9 в Staticache (жмём один раз, HIT отдаёт готовый .br), `music.js`/`lampainit.js` → immutable при ?v, Cache-Control всей статике (vender/fonts/lang/ext), постеры `/tmdb/img` — immutable-год, AppCacheVersion без ticks процесса (рестарт не сбрасывает клиентские кеши), CatalogWarmup v2 (парс рядов → прогрев постеров и деталей карточек), preload бандла + динамический ?v CSS + jquery/scrollbar min в вендоре index.html, быстрый вотчер Lampa (25 мс вместо 200) с идемпотентным appload, changelog вынесен сюда (−6.5 КБ с каждого старта).
